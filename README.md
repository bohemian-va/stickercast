# Stickercast SEO Website

Static GitHub Pages-ready site. Upload all files in this folder to your repository root.

## After publishing
1. Confirm `https://stickercast.com/sitemap.xml` loads.
2. Submit sitemap in Google Search Console.
3. Replace `og-image.png` with a branded 1200x630 image when available.
4. Keep blog posts updated and add service/location pages only when they are genuinely useful, not doorway pages.
